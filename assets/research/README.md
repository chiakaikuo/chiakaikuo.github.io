# Research figure

`abjm-chambers.svg` reproduces Figure 1 from:

S. He, Y.-T. Huang and C.-K. Kuo, *The ABJM Amplituhedron*, JHEP 09 (2023) 165.

- Paper: https://doi.org/10.1007/JHEP09(2023)165
- Figure source: https://arxiv.org/html/2306.00951v2#S1.F1
- License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/
- License statement: https://link.springer.com/article/10.1007/JHEP09(2023)165#rightslink

The original vector paths, colors, and geometry are preserved. Eight numeric labels were converted from HTML/MathML foreign objects to equivalent standalone SVG text so the image does not depend on arXiv's stylesheets. A descriptive SVG title and namespace were added. The website includes attribution, a source link, and notice of the label-format change.
